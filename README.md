Here’s a simple code snippet demonstrating how to build a basic linear regression model using Python and Scikit-Learn:

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

# Sample data
X = np.array([[1], [2], [3], [4], [5]])
y = np.array([1, 3, 2, 3, 5])

# Create a linear regression model
model = LinearRegression()
model.fit(X, y)

# Predict values
predicted = model.predict(X)

# Visualization
plt.scatter(X, y, color='blue')
plt.plot(X, predicted, color='red')
plt.title('Linear Regression Example')
plt.xlabel('X values')
plt.ylabel('Predicted Y values')
plt.show()
```

This code snippet illustrates a fundamental concept of regression in AI, which is vital for various predictive modeling applications.
